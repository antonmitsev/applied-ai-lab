# Source governance

The Plumbing Assistant source catalogue is governed by
[PA-SOURCE-001](plumbing-assistant-source-governance.md).

- [Source manifest schema](source-manifest.schema.json)
- [Index manifest schema](index-manifest.schema.json)
- [WP-01 source registry](../../sources/plumbing-assistant/manifest.json)

The registry is intentionally empty while WP-01 remains deferred. Do not add or
upload documents without completing the review and rights fields required by the
governance specification.
