# Audit register

The project uses two audit scopes so requirements maturity is never confused
with working software or public-release approval.

| Audit | Scope | Status | Decision |
| --- | --- | --- | --- |
| [PA-AUDIT-001](plumbing-assistant-project-definition-audit.md) | Product definition, requirements, architecture, policies, contracts, traceability, repository readiness | Closed | Accepted for implementation |
| [PA-AUDIT-002](plumbing-assistant-implementation-readiness-audit.md) | Code, tests, reviewed sources, benchmarks, deployment, operations, external reviews, release evidence | Not started | No public-release decision |
| [PA-AUDIT-001-WP](plumbing-assistant-requirements-v0.1-audit.md) | Original detailed findings and remediation history | Archived | Preserved for provenance |

The original audit path remains as an archived working paper so old links and
commit history remain understandable.
