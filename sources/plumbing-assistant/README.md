# Plumbing Assistant source registry

`manifest.json` is the repository-owned source of truth for curated documents.
It currently contains nine in-review records. They are metadata-only candidates
and are not eligible for production source-body indexing because rights,
jurisdiction, technical scope, and qualified review are still pending. Six
records support repository-owned paraphrased radiator KB units; the original
pages and PDF are not stored here.

Before adding records, follow
[PA-SOURCE-001](../../docs/sources/plumbing-assistant-source-governance.md) and
validate against the pinned
[source manifest schema](../../docs/sources/source-manifest.schema.json).

Do not commit source document bytes unless their redistribution decision is
explicitly approved. Public availability alone is not approval.
